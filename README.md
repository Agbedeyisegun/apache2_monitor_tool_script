Introduction

This script automates the installation and configuration of Apache2 on a Linux system. It also downloads and configures a sample website template.

Features

- Installs Apache2 and its dependencies
- Configures Apache2 to run as a service
- Downloads and configures a sample website template (2098_health)
- Restarts and enables Apache2 service

Requirements

- Linux system (tested on Ubuntu-based systems)
- Internet connection for downloading website template

Usage

1. Clone this repository to your local machine.
2. Make the script executable by running chmod +x apache2-install.sh.
3. Run the script by executing ./apache2-install.sh.
4. Follow the on-screen instructions and wait for the script to complete.
